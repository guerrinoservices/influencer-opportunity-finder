## How to Host Privacy Policy

### Option 1: GitHub Pages (Free, Recommended)
1. Create a GitHub repository
2. Upload PRIVACY_POLICY.md
3. Enable GitHub Pages in settings
4. URL: `https://yourusername.github.io/repo-name/PRIVACY_POLICY`

### Option 2: Your Website
1. Convert markdown to HTML or use as-is
2. Upload to your web hosting
3. URL: `https://yourdomain.com/privacy-policy`

### Option 3: Google Sites (Free)
1. Create a new Google Site
2. Copy privacy policy content
3. Publish site
4. Use the published URL

## Accessing Legal Documents

Users can access legal documents by:
1. Opening the extension popup
2. Clicking the "About" tab (ℹ️)
3. Scrolling to "Legal" section
4. Clicking desired document link

Documents open in new tab for easy reading.
